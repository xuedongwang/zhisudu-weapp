# 纸速打（zhisudu-weapp）

微信小程序：一分钟生成可打印的练习纸。24 种纸型（横线纸、方格纸、点阵纸、空白纸、草图纸、田字格、米字格、书法格、拼音四线三格、口算纸、坐标纸、等距网格、五线谱纸、吉他六线谱、康奈尔笔记纸、周计划表、分镜纸、会议记录纸、项目规划纸等），支持 A4 / 16K / B5 / A5 四种纸规与单页多区块版面（一页可切 2×2 或上下多格、每区独立选纸型），参数化配置（格宽/行距/边距/线色/线型），300DPI 导出 PNG，通过微信文件直达电脑打印。

## 功能

- 24 种纸型参数化生成，按用途分为基础纸型 / 练字与书写 / 学科作业 / 音乐乐谱 / 笔记与计划五类
- 纸张规格 A4 / 16K / B5 / A5，纵向 / 横向，导出像素按规格与 DPI 现算
- 单页多区块：整页 / 上下两格 / 上下三格 / 四宫格，每个区块独立选择纸型与尺寸参数
- 纸型专属参数：康奈尔笔记纸线索栏宽度、周计划表行数可调；空白纸无可调尺寸，配置页自动隐藏该行
- 实时预览 + 吸底导出，300DPI 高清（低配机型自动降级 200DPI 并提示）
- 导出后一键「分享」（微信文件传输助手）或保存相册，附打印指引
- 自定义模板（上限 20）/ 纸型收藏 / 最近记录 / 打印历史（含累计张数）
- 转发卡片：带完整整页参数，好友点开即是同一张纸
- 云开发：登录（openid）、用户头像昵称云端同步

## 目录结构

```
├── app.js / app.json / app.wxss   # 入口与全局配置（含 tabBar）
├── pages/
│   ├── home/      # 首页：纸型分类分组 + 收藏 + 最近记录
│   ├── config/    # 配置页：预览 + 参数面板（纸规/版式/区块）+ 导出
│   ├── success/   # 导出成功页：分享 / 相册 / 打印指引
│   ├── mine/      # 我的：头像昵称、模板管理、打印历史、收藏、客服、关于
│   ├── favs/      # 我的收藏
│   ├── history/   # 打印历史（累计张数 + 常用纸型 + 一键重打）
│   └── about/     # 关于与版本历史
├── utils/
│   ├── papers.js    # 纸型 / 纸张规格 / 版式 定义（单一数据源）
│   ├── draw.js      # canvas 2d 绘制引擎（盒子坐标系，mm 口径）
│   ├── exporter.js  # 离屏导出（300DPI→200DPI 降级）
│   ├── store.js     # 模板/收藏/最近记录/打印历史（本地 storage）
│   ├── thumbs.js    # 纸型与版面缩略图生成与缓存（带版本号）
│   ├── track.js     # 埋点统一入口（wx.reportEvent 白名单）
│   ├── cloud.js     # 云开发用户资料同步
│   └── icons.js     # SVG 图标 data-uri
└── cloudfunctions/login/          # 云函数：openid 登录
```

## 开发

微信开发者工具打开本项目（需开通云开发环境，上传 `cloudfunctions/login` 云函数，并创建 `users` 集合）。

# 纸速打（zhisudu-weapp）

微信小程序：一分钟生成可打印的中文练习纸。田字格、米字格、拼音四线三格、口算纸等 8 种儿童场景纸，参数化配置（格宽/边距/线色/线型），300DPI 导出 PNG，通过微信文件直达电脑打印。

## 功能

- 8 种纸型参数化生成（A4，纵向/横向）
- 实时预览 + 吸底导出，300DPI 高清（低配机型自动降级 200DPI 并提示）
- 导出后一键「发到电脑」（微信文件传输助手）或保存相册，附打印指引
- 自定义模板（上限 20）/ 纸型收藏 / 最近记录一键复用
- 云开发：登录（openid）、用户头像昵称云端同步

## 目录结构

```
├── app.js / app.json / app.wxss   # 入口与全局配置（含 tabBar）
├── pages/
│   ├── home/      # 首页：纸型分组 + 收藏 + 最近记录
│   ├── config/    # 配置页：预览 + 参数面板 + 导出
│   ├── success/   # 导出成功页：发到电脑 / 相册 / 打印指引
│   ├── mine/      # 我的：头像昵称、模板管理、收藏、客服、关于
│   ├── favs/      # 我的收藏
│   └── about/     # 关于与版本历史
├── utils/
│   ├── papers.js    # 纸型定义（单一数据源）
│   ├── draw.js      # canvas 2d 绘制引擎（mm 口径）
│   ├── exporter.js  # 离屏导出（300DPI→200DPI 降级）
│   ├── store.js     # 模板/收藏/记录（本地 storage）
│   ├── thumbs.js    # 纸型缩略图生成与缓存
│   ├── cloud.js     # 云开发用户资料同步
│   └── icons.js     # SVG 图标 data-uri
└── cloudfunctions/login/          # 云函数：openid 登录
```

## 开发

微信开发者工具打开本项目（需开通云开发环境，上传 `cloudfunctions/login` 云函数，并创建 `users` 集合）。
